## 快速入门

### 首次登录
1. 访问系统地址，使用管理员账号登录
2. 首次登录后请前往「系统设置」→「个人信息」完善个人资料
3. 建议立即修改默认密码

### 角色说明
| 角色 | 权限说明 |
|------|---------|
| 管理员 | 系统全部权限 |
| 技术支持 | 处理工单、管理知识库 |
| 客户成功 | 查看客户数据、跟进满意度 |
| 客户 | 创建工单、查看自己的工单 |

## 工作台

### 仪表盘
- **今日新增**: 当天创建的工单数量
- **处理中**: 尚未解决的工单数量
- **已解决**: 当月已解决的工单数量
- **SLA预警**: 即将超时的工单数量

### 我的待办
- 显示分配给您且尚未完成的工单
- 点击可直接跳转到工单详情

## 工单管理

### 创建工单
1. 点击「创建工单」按钮
2. 填写工单信息：
   - **客户**: 选择提交工单的客户（必填）
   - **标题**: 简洁描述问题（必填）
   - **类型**: Bug/咨询/需求/投诉
   - **优先级**: 紧急/高/中/低
   - **问题描述**: 详细描述问题（必填）
   - **附件**: 支持图片、文档等
3. 点击「提交工单」

### 工单状态说明
```
新建 → 已确认 → 处理中 → 待验证 → 已解决 → 已关闭
                  ↓
               已撤回/已合并
```

### 工单操作
| 操作 | 说明 |
|------|------|
| 分配 | 将工单分配给其他人处理 |
| 开始处理 | 确认开始处理此工单 |
| 待验证 | 处理完成后，等待客户确认 |
| 解决 | 标记为已解决 |
| 关闭 | 关闭工单 |
| 合并 | 将多个相关工单合并 |
| 拆分 | 将一个工单拆分为多个 |
| 催单 | 客户可催促处理 |

### 回复与沟通
- **公开回复**: 客户可见
- **内部备注**: 仅内部人员可见

## 客户管理

### 客户列表
- 支持按名称、等级、行业筛选
- 支持导入导出

### 客户详情
- **基本信息**: 名称、等级、行业、规模等
- **联系人**: 管理客户的联系人
- **工单记录**: 查看该客户的所有工单
- **统计分析**: 工单数量、解决率、满意度

### 客户等级
| 等级 | SLA时限 |
|------|---------|
| 标准 | 首次响应8h，解决72h |
| 高级 | 首次响应4h，解决24h |
| 旗舰 | 首次响应1h，解决8h |

## 知识库

### 文章管理
- 创建知识库文章，供客户自助查询
- 支持分类、标签管理
- 支持内部/外部可见性设置

### AI智能推荐
- 创建工单时，系统会推荐相关知识库文章
- 基于问题描述智能匹配

### 文章可见性
| 类型 | 说明 |
|------|------|
| 全部可见 | 所有人均可查看 |
| 仅对内 | 仅内部人员可见 |
| 对客户可见 | 客户登录后可查看 |

## 报表中心

### 内置报表
1. **工单统计报表**: 按时间、类型、状态统计
2. **客服绩效报表**: 各客服处理工单数量、解决率
3. **SLA执行报表**: SLA达成率统计
4. **客户分析报表**: 按客户维度分析
5. **知识库使用报表**: 浏览量、搜索关键词

### 自定义报表
- 选择数据维度
- 设置筛选条件
- 选择展示图表类型

### 报表订阅
- 配置定期发送报表
- 设置接收人邮箱
- 支持PDF/Excel格式

## 常见功能说明

### 草稿保存
- 创建工单时，内容会自动保存为草稿
- 下次进入时自动恢复

### 工单标签
- 为工单添加标签，便于分类和检索
- 支持自定义标签

### 抄送功能
- 工单处理过程中，可抄送给相关人员
- 被抄送人可查看工单进展

### SLA预警
- 工单即将超时时，系统自动标记预警
- 处理人收到通知提醒

### 满意度评价
- 工单解决后，客户可进行满意度评价
- 支持评分和文字反馈
- 差评自动提醒管理员

## 常见问题

**Q: 无法登录怎么办？**
A: 检查用户名密码是否正确，联系管理员重置密码。

**Q: 工单分配后没收到通知？**
A: 检查通知设置，确认通知渠道已开启。

**Q: 如何导出工单数据？**
A: 在工单列表页面，点击「导出」按钮，支持Excel格式。

**Q: 客户如何自助查询工单进度？**
A: 客户通过独立登录入口查看自己提交的工单。
