# 客户工单系统 部署文档

## 一、环境要求

### 1.1 硬件要求
- CPU: 2核+
- 内存: 4GB+
- 硬盘: 50GB+

### 1.2 软件要求
- JDK: 17+
- MySQL: 8.0+
- Node.js: 18+
- Nginx: 1.20+

## 二、项目结构

```
ticket-system/
├── backend/          # 后端Spring Boot项目
├── frontend/         # 前端Vue项目
└── docs/            # 文档
```

## 三、数据库配置

### 3.1 创建数据库
```sql
CREATE DATABASE ticket_system DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 3.2 初始化数据
```bash
mysql -u root -p ticket_system < backend/src/main/resources/sql/init.sql
```

## 四、后端部署

### 4.1 修改配置
编辑 `backend/src/main/resources/application.yml`：

```yaml
server:
  port: 8080

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/ticket_system?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: root
    password: your_password

  mail:
    host: smtp.example.com
    username: noreply@example.com
    password: your_email_password

jwt:
  secret: your-jwt-secret-key-min-32-chars
  expiration: 86400
```

### 4.2 构建项目
```bash
cd backend
mvn clean package -DskipTests
```

### 4.3 运行项目
```bash
# 开发环境
mvn spring-boot:run

# 生产环境
java -jar target/ticket-system.jar
```

## 五、前端部署

### 5.1 修改配置
编辑 `frontend/.env.production`：
```env
VITE_API_BASE_URL=http://your-domain.com/api
```

### 5.2 构建项目
```bash
cd frontend
npm install
npm run build
```

### 5.3 Nginx配置
编辑 `/etc/nginx/conf.d/ticket.conf`：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /var/www/ticket-system/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # API代理
    location /api {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # 文件上传大小限制
    client_max_body_size 50m;
}
```

### 5.4 部署静态文件
```bash
cp -r frontend/dist/* /var/www/ticket-system/frontend/
```

### 5.5 重启Nginx
```bash
nginx -t
systemctl reload nginx
```

## 六、系统配置

### 6.1 初始化管理员账号
系统启动后，使用以下信息登录：
- 用户名: admin
- 密码: admin123

**⚠️ 首次登录后请立即修改密码！**

### 6.2 配置钉钉Webhook（如需）
1. 进入系统管理 -> 钉钉集成
2. 填入AppKey和AppSecret
3. 测试连接

### 6.3 配置SLA
系统预置了三个SLA等级：
- 标准服务: 首次响应8小时，解决72小时
- 高级服务: 首次响应4小时，解决24小时
- 旗舰服务: 首次响应1小时，解决8小时

## 七、开机自启配置

### 7.1 创建systemd服务
编辑 `/etc/systemd/system/ticket.service`：

```ini
[Unit]
Description=Ticket System
After=network.target mysql.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/ticket-system/backend
ExecStart=/usr/bin/java -jar ticket-system.jar
Restart=always

[Install]
WantedBy=multi-user.target
```

### 7.2 启用服务
```bash
systemctl daemon-reload
systemctl enable ticket
systemctl start ticket
```

## 八、备份策略

### 8.1 数据库备份脚本
```bash
#!/bin/bash
DATE=$(date +%Y%m%d%H%M)
BACKUP_DIR=/backup/ticket
mysqldump -u root -p ticket_system > $BACKUP_DIR/ticket_$DATE.sql
find $BACKUP_DIR -name "*.sql" -mtime +30 -delete
```

### 8.2 设置定时备份
```bash
crontab -e
# 每天凌晨2点备份
0 2 * * * /opt/backup-ticket.sh
```

## 九、监控配置

### 9.1 健康检查
```bash
curl http://localhost:8080/actuator/health
```

### 9.2 日志查看
```bash
tail -f /opt/ticket-system/backend/logs/ticket.log
```

## 十、常见问题

### Q1: 启动失败，端口被占用
```bash
# 查找占用端口的进程
lsof -i:8080
# 或修改application.yml中的端口
```

### Q2: 数据库连接失败
- 检查MySQL服务状态
- 验证用户名密码
- 检查数据库是否存在

### Q3: 前端无法访问API
- 检查Nginx配置
- 检查API代理是否正常
- 检查后端服务是否启动

## 十一、升级指南

### 11.1 后端升级
```bash
cd backend
mvn clean package -DskipTests
systemctl stop ticket
cp target/ticket-system.jar /opt/ticket-system/backend/
systemctl start ticket
```

### 11.2 前端升级
```bash
cd frontend
npm run build
cp -r dist/* /var/www/ticket-system/frontend/
```
