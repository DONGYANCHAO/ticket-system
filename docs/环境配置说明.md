## 环境概述

工单系统支持三种运行环境：

| 环境 | 用途 | 配置文件 |
|------|------|----------|
| **dev** (开发) | 本地开发调试 | `application-dev.yml` / `.env.development` |
| **test** (测试) | 自动化测试、CI/CD | `application-test.yml` / `.env.test` |
| **prod** (生产) | 正式生产部署 | `application-prod.yml` / `.env.production` |

## 后端环境配置

### 配置文件位置

```
backend/src/main/resources/
├── application.yml          # 主配置（环境无关）
├── application-dev.yml      # 开发环境
├── application-test.yml     # 测试环境
└── application-prod.yml     # 生产环境
```

### Maven 多环境打包

#### 1. 开发环境（默认）

```bash
# 默认使用 dev 环境
mvn clean package

# 或显式指定
mvn clean package -Pdev
```

#### 2. 测试环境

```bash
# 测试环境打包（包含 JaCoCo 覆盖率检查）
mvn clean package -Ptest

# 运行测试并生成覆盖率报告
mvn clean test -Ptest

# 覆盖率报告位置
# target/site/jacoco/index.html
```

#### 3. 生产环境

```bash
# 生产环境打包（跳过测试）
mvn clean package -Pprod

# 生成的 jar 文件
# target/ticket-system-1.0.0.jar
```

### 后端环境变量

| 变量名 | 开发环境 | 测试环境 | 生产环境 |
|--------|----------|----------|----------|
| `DB_HOST` | localhost | localhost | mysql |
| `DB_PORT` | 3306 | 3306 | 3306 |
| `DB_USERNAME` | root | root | ticket |
| `DB_PASSWORD` | (空) | (空) | (必须设置) |
| `REDIS_HOST` | localhost | localhost | redis |
| `REDIS_PORT` | 6379 | 6379 | 6379 |
| `JWT_SECRET` | dev-secret-key... | test-secret-key... | (必须设置强密钥) |
| `LOG_LEVEL` | DEBUG | INFO | WARN |

## 前端环境配置

### 配置文件位置

```
frontend/
├── .env.development    # 开发环境
├── .env.test          # 测试环境
├── .env.production    # 生产环境
└── vite.config.js     # Vite 配置
```

### 前端多环境构建

#### 1. 开发环境

```bash
# 启动开发服务器
npm run dev

# 或
pnpm dev
```

#### 2. 测试环境

```bash
# 构建测试环境版本
npm run build:test

# 预览构建结果
npm run preview
```

#### 3. 生产环境

```bash
# 构建生产环境版本（默认）
npm run build

# 或显式指定
npm run build:prod
```

### 前端环境变量

| 变量名 | 开发环境 | 测试环境 | 生产环境 |
|--------|----------|----------|----------|
| `VITE_API_BASE_URL` | http://localhost:8080/api | http://localhost:8080/api | /api |
| `VITE_APP_TITLE` | 工单系统(开发版) | 工单系统(测试版) | 工单系统 |
| `VITE_ENABLE_DEBUG` | true | true | false |
| `VITE_SHOW_API_DOCS` | true | true | false |
| `VITE_LOG_LEVEL` | debug | info | error |

## 配置切换指南

### 后端配置切换

#### 方式一：通过 Maven Profile

```bash
# 开发环境
mvn spring-boot:run -Pdev

# 测试环境
mvn spring-boot:run -Ptest

# 生产环境
mvn spring-boot:run -Pprod
```

#### 方式二：通过环境变量

```bash
# 设置环境变量
export SPRING_PROFILES_ACTIVE=prod

# 运行应用
java -jar ticket-system-1.0.0.jar
```

#### 方式三：通过命令行参数

```bash
java -jar ticket-system-1.0.0.jar --spring.profiles.active=prod
```

### 前端配置切换

#### 方式一：通过 npm 脚本

```bash
# 开发环境
npm run dev

# 测试环境
npm run build:test

# 生产环境
npm run build:prod
```

#### 方式二：通过 Vite 命令

```bash
# 开发环境
vite --mode development

# 测试环境
vite build --mode test

# 生产环境
vite build --mode production
```

### Docker 环境切换

```bash
# 开发环境
make deploy-dev

# 测试环境
make deploy-test

# 生产环境
make deploy-prod

# 或手动设置环境变量
export SPRING_PROFILES_ACTIVE=prod
docker-compose up -d
```

## 打包构建指南

### 完整构建流程

#### 1. 开发环境构建

```bash
# 后端
cd backend
mvn clean package -Pdev -DskipTests

# 前端
cd frontend
npm install
npm run build:dev
```

#### 2. 测试环境构建

```bash
# 后端（包含测试和覆盖率检查）
cd backend
mvn clean package -Ptest

# 前端
cd frontend
npm install
npm run build:test
```

#### 3. 生产环境构建

```bash
# 后端（跳过测试）
cd backend
mvn clean package -Pprod -DskipTests

# 前端
cd frontend
npm install
npm run build:prod
```

### Docker 构建

```bash
# 构建所有服务
docker-compose build

# 构建特定服务
docker-compose build backend
docker-compose build frontend

# 不使用缓存构建
docker-compose build --no-cache
```

### CI/CD 集成示例

#### GitHub Actions 配置片段

```yaml
name: Build and Test

on: [push, pull_request]

jobs:
  backend:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Set up JDK 17
        uses: actions/setup-java@v3
        with:
          java-version: '17'
          distribution: 'temurin'
      - name: Build with Maven (Test Profile)
        run: mvn clean package -Ptest
      - name: Upload coverage to Codecov
        uses: codecov/codecov-action@v3

  frontend:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Set up Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '18'
      - name: Install dependencies
        run: cd frontend && npm install
      - name: Run tests
        run: cd frontend && npm run test:coverage
      - name: Build
        run: cd frontend && npm run build:prod
```

## 常见问题

### Q: 如何查看当前激活的环境？

**后端：**
```bash
# 查看日志输出，会显示激活的 profile
# 或通过 Actuator 端点
curl http://localhost:8080/api/actuator/info
```

**前端：**
```javascript
// 在浏览器控制台查看
console.log(import.meta.env)
```

### Q: 环境变量不生效怎么办？

1. 检查配置文件命名是否正确（必须以 `.env.` 开头）
2. 检查变量名是否以 `VITE_` 开头（前端）
3. 重启开发服务器
4. 清除缓存后重新构建

### Q: 如何在本地模拟生产环境？

```bash
# 后端
mvn spring-boot:run -Pprod \
  -DDB_HOST=localhost \
  -DDB_PASSWORD=your_password \
  -DJWT_SECRET=your_secret

# 前端
npm run build:prod
npm run preview
```
